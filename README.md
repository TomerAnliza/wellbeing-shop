# Lec6 — אפליקציית מעקב פעילות ספורטיבית

פרויקט משותף לעבודה של כמה סוכני AI (Claude, Codex ועוד) ובני אדם יחד.

**מה בונים:** אפליקציית Web שבה משתמש מתחיל אימון בלחיצה, רואה אותו רץ
עם טיימר, מרחק וקלוריות, שומר אותו בסיום, ורואה את ההתקדמות השבועית שלו
מול יעד.

העיקרון: **עיצוב לפני מסמכים, ומסמכים לפני קוד.** העיצוב הוא מקור האמת,
ממנו נגזר האפיון, וממנו נכתב הקוד — והכול מתועד במסמכים ברורים לבני אדם
תחת [docs/](docs/).

- **הקוד והתיעוד חיים ב-GitHub:** https://github.com/TomerAnliza/wellbeing-app
- סוכן שמצטרף מתחיל ב-[AGENTS.md](AGENTS.md), ואז `git pull`
- **העיצוב — מקור האמת:** [design/](design/), מתועד ב-[docs/design-system.md](docs/design-system.md)
- אפיון המסכים הפעיל: [docs/spec-fitness-mvp-screens.md](docs/spec-fitness-mvp-screens.md)
- הסטאק המומלץ: [docs/tech-stack.md](docs/tech-stack.md)
