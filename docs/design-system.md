# שפה עיצובית — מחולצת מהפרוטוטייפ

- **תאריך:** 23 בספטמבר 2026
- **סטטוס:** מקור האמת לעיצוב. כל ערך כאן חולץ מתוך הפרוטוטייפ עצמו, לא הומצא
- **מקור:** [`design/Wellness App.html`](../design/Wellness%20App.html)

## על המסמך

קובץ העיצוב הוא פרוטוטייפ React חי — חבילה שמפרקת את עצמה בדפדפן.
לצפייה: פתיחת הקובץ בדפדפן (דורש JavaScript).

כל הערכים שלהלן **חולצו מהפרוטוטייפ עצמו** ולא פורשו. מסגרת מכשיר ה-iOS
שעוטפת אותו אינה חלק מהמוצר.

## צבעים

הפלטה כולה בנויה ב-`oklch` סביב גוון קבוע **300** (סגול-לבנדר), ורק
הבהירות והרוויה משתנות. זו פלטה שיטתית — אין בה צבע "אקראי".

| תפקיד | ערך | שימוש בפרוטוטייפ |
|---|---|---|
| רקע דף | `#e9e5de` | בז' חם, מחוץ למכשיר |
| רקע מסך | `#f7f4ef` | הרקע של האפליקציה עצמה |
| משטח כרטיס | `#fffdf8` | כל הכרטיסים והרשימות |
| גבול כרטיס | `rgba(28,27,25,0.07)` | מסגרת דקה מאוד |
| טקסט ראשי | `#1c1b19` | כמעט-שחור חמים, לא `#000` |
| טקסט משני | `rgba(28,27,25,0.5)` | כותרות משנה, תאריכים |
| טקסט שלישוני | `rgba(28,27,25,0.45)` | תוויות, רמזים |
| **מותג** | **`oklch(0.62 0.13 300)`** | טבעת התקדמות, כפתור ראשי, עמודות פעילות |
| מותג — hover | `oklch(0.55 0.13 300)` | גם צבע הטאב הפעיל |
| מותג — אייקון | `oklch(0.52 0.13 300)` | אייקונים על רקע בהיר |
| מותג — רקע רך | `oklch(0.95 0.025 300)` | רקע כרטיס התובנה |
| מותג — טקסט על רך | `oklch(0.4 0.05 300)` | טקסט בתוך כרטיס התובנה |
| מותג — ניטרלי | `oklch(0.9 0.03 300)` | עמודות לא-פעילות, אווטאר |
| רקע מסך חי | `#1a1820` | מסך האימון החי בלבד |
| מבטא על כהה | `oklch(0.72 0.15 300)` | נקודת הדופק הפועמת |

**הערת נגישות:** `oklch(0.62 0.13 300)` על `#fffdf8` אינו עובר AA לטקסט
קטן. בפרוטוטייפ הוא משמש לכפתור עם טקסט לבן ולאלמנטים גרפיים — שימוש תקין.
**אין להשתמש בו לטקסט גוף על רקע בהיר.** לטקסט על רקע רך יש את
`oklch(0.4 0.05 300)`, שנבחר בדיוק לכך. טרם נמדד בכלי ניגודיות.

## טיפוגרפיה

**גופן יחיד: Rubik**, בתת-קבוצה עברית, עם `system-ui, sans-serif` כגיבוי.
בפרוטוטייפ הוא נטען מ-Google Fonts ונארז כ-woff2 בתוך החבילה.

| שימוש | גודל | משקל | הערות |
|---|---|---|---|
| כותרת מסך | 23px | 600 | `letter-spacing: -0.01em` |
| כותרת כרטיס | 28px | 600 | מספר המדד הגדול |
| שם פריט | 17px / 15.5px | 600 / 500 | |
| גוף | 14.5px | 400 | |
| משני | 13px | 400 | |
| תווית | 11.5px | 400 | |
| תווית טאב | 10.5px | 500 | |
| **שעון האימון החי** | **68px** | **300** | `font-variant-numeric: tabular-nums` |

המשקל הדק (300) לשעון הגדול הוא החלטה מכוונת: מספר ענק במשקל רגיל היה
כבד מדי. `tabular-nums` מונע ריצוד של הספרות בזמן שהטיימר רץ.

## אייקונים

**Material Symbols Rounded**, נטען כ-woff2. בפרוטוטייפ בשימוש:

`local_fire_department` · `bolt` · `flag` · `notifications` · `favorite` ·
`straighten` · `play_arrow` · `check_circle` · `today` · `add_circle` ·
`insights` · `person` · `directions_run` · `directions_walk` ·
`pedal_bike` · `pool` · `self_improvement` · `fitness_center`

גודל: 17–26px לפי הקשר, 23px בטאבים.

## כיווניות

`dir="rtl"` על מיכל האפליקציה. הטקסט בכפתורי הבחירה מיושר `text-align: right`.

**לקח למימוש:** הפרוטוטייפ משתמש ב-`padding` ו-`margin` פיזיים. בקוד האמיתי
יש להשתמש ב-logical properties (`padding-inline`, `margin-inline-start`)
כדי שה-RTL לא יישבר.

## תנועה

- `@keyframes pulseDot` — 1.6s, `ease-in-out`, אינסופי. נקודת "אימון פעיל"
- מעברי `hover` על כפתורים וכרטיסים
- טוסט שנעלם אחרי **2600ms**

**חסר בפרוטוטייפ:** אין `prefers-reduced-motion`. חובה להוסיף במימוש.

## מה הפרוטוטייפ מדגים, ומה לא

**מדגים:** ארבעה מסכים עם ניווט טאבים עובד, אימון חי עם טיימר אמיתי,
שמירת אימון שמעדכנת את מסך היום, וטוסט אישור.

**לא מדגים, וצריך עיצוב:** הרשמה, התחברות, שאלון הקמה, מצבי ריק, מצבי
שגיאה, מצבי טעינה, דף תדמית, ותצוגת דסקטופ. הפרוטוטייפ הוא מובייל בלבד.
